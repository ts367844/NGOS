Task 2: Multithreading Implementation

Task Three Concurrent Threads in Python

Implement and execute three threads concurrently within a single process address space:

  • •Thread 1: Prints numbers from 1 to 10
  • •Thread 2: Prints alphabets from A to J
  • •Thread 3: Prints squares of numbers from 1 to 10 (1, 4, 9, ..., 100)
multithread_demo.py
import threading import time import sys def print_numbers(): for i in range(1, 11): sys.stdout.write(f"[Thread-1] Number: {i}\n") sys.stdout.flush() time.sleep(0.01) def print_alphabets(): for ch in "ABCDEFGHIJ": sys.stdout.write(f"[Thread-2] Alphabet: {ch}\n") sys.stdout.flush() time.sleep(0.01) def print_squares(): for i in range(1, 11): sys.stdout.write(f"[Thread-3] Square: {i}² = {i*i}\n") sys.stdout.flush() time.sleep(0.01) # Initialize 3 concurrent worker threads t1 = threading.Thread(target=print_numbers, name="T1") t2 = threading.Thread(target=print_alphabets, name="T2") t3 = threading.Thread(target=print_squares, name="T3") # Launch threads concurrently t1.start(); t2.start(); t3.start() # Await thread completion t1.join(); t2.join(); t3.join() print("[Main] All concurrent threads executed successfully.")

Section A: Operating System Fundamentals

Q1 What is an Operating System? Explain any four functions.

Definition: An Operating System (OS) is system software that acts as an intermediary between computer hardware and user software applications, managing resources and providing runtime services.

  • •1. Process Management: Creates, schedules, synchronizes, and terminates processes on the CPU.
  • •2. Memory Management: Allocates RAM addresses and coordinates virtual memory demand paging.
  • •3. File Management: Organizes files into directory trees, managing read/write permissions and storage inodes.
  • •4. Device Management: Controls peripheral I/O devices via device drivers and coordinates interrupts/buffers.

Q4 What is Deadlock? List its four necessary conditions.

Definition: Deadlock is a permanent stalled state where two or more processes wait indefinitely for resources held by each other.

  • •1. Mutual Exclusion: At least one resource is held in non-shareable mode (one process at a time).
  • •2. Hold and Wait: A process holds resources while requesting additional resources held by other processes.
  • •3. No Preemption: Resources cannot be forcibly taken away; they are only released voluntarily.
  • •4. Circular Wait: A closed cycle of processes exists where each process waits for a resource held by the next.

Section D: Analytical & Scenario Questions

Q11 Explain How Deadlock May Occur and Two Prevention Methods

Deadlock Occurrence Scenario: Suppose Process P1 holds Resource R1 and requests R2, while Process P2 holds Resource R2 and requests R1. Each process waits for the other to release resources, resulting in a mutual permanent standstill (“Deadlock”).

  • •Method 1: Break Hold and Wait — Require a process to request all required resources simultaneously before execution begins. If any resource cannot be allocated, the process releases all held resources and waits.
  • •Method 2: Break Circular Wait — Enforce a strict linear ordering (numbering) on all resources. Processes must request resources only in strictly ascending numerical order, preventing any circular cycle.
